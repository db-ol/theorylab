# Repository instructions

Keep TheoryLab independent of ABRSM and use original instructional examples and assessment items. Verify scope and scoring against current primary sources. Update the syllabus matrix with any change in objective coverage or validation.

Preserve spelled pitches, exact durations, deterministic generators, and stable record identifiers. Keep assessment stems and options in British English. Use natural Simplified Chinese with full width punctuation for instruction and feedback. Add comments only where intent needs clarification.

Use periods and commas in prose. Avoid dash punctuation and semicolons. Keep repository identifiers, flags, and filenames literal. Keep assistant and vendor branding out of authored metadata, preserving licenses and required attribution.

Show Aaron the complete proposed content and destination before external publication. Wait for his explicit approval before pushes, pull requests, messages, shared edits, or hosting. Use the repository pull request template when present. Otherwise follow the format of recent merged pull requests.
